# Methods extension (controlled prototype)
This branch preserves the preceding empirical baseline. It adds bounded assignment on preverified exact candidates, exact-key deduplication and signed cluster evidence, and typed edge masks/audit. The tests use controlled examples, NOT expert gold or real-graph trained IRRL. No previous empirical metrics are changed. Proposed structured Qwen output, full chemical resolver, provenance inference, adaptive plan, evidence reward and independent biological validation remain outside this prototype.

Run: PYTHONPATH=. python tests/test_methods_extension.py
